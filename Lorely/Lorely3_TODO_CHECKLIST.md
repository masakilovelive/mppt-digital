# Lorely3 航行電力制御 今後の作業チェックリスト

## 使い方

本チェックリストは `Lorely3` 実験仕様を実行可能な状態へ進めるための作業順序である。
高電力回路を扱うため、保護回路および単体確認が完了するまで二電源を同一DCバスへ接続しない。

## A. 要件確定

- [ ] 水中翼モード `H1/H2/H3` の負荷電力プロファイルを確定する。
- [ ] 排水モード `D1/D2` の負荷電力プロファイルを確定する。
- [ ] 各シナリオの電圧ディップ、切替時間、電流、Alertの合格値を決める。
- [ ] PV用安定化電源の型式、最大電圧、最大電流、0-10V外部制御仕様を確認する。
- [ ] Battery/MPPT用安定化電源の型式、最大電圧、最大電流、0-10V外部制御仕様を確認する。
- [ ] MAP-300実機を試験へ含めるか、安定化電源で特性模擬するか決定する。
- [ ] ELDCの定義、定格、接続、供給ON条件を確定する。

## B. アナログ指令回路

- [ ] MCP4728を `3.3V DAC + ゲイン約3.03` で使うか、`5V DAC + I2Cレベル変換 + ゲイン2` で使うか決定する。
- [x] MCP4728単体でCH A/Bの出力変化を確認する。実測: CH A code 614で約0.49V、CH B code 983で約0.79V。
- [ ] 採用ゲインで0-10V変換回路を設計する。
- [ ] 各アナログ指令出力へ直列抵抗と過電圧保護を実装する。
- [ ] 0V、25%、50%、75%、100%指令で各出力電圧を実測する。
- [ ] UIおよびESP32のDAC換算式を採用回路へ合わせて修正する。

## C. DACチャンネル拡張

- [ ] 二電源と負荷の可変制御に必要な5ch以上を確保する。
- [ ] MCP4728を2個使用する場合、I2Cアドレス設定と配線を確定する。
- [ ] PV電源電圧指令chを割り当てる。
- [ ] PV電源電流制限chを割り当てる。
- [ ] Battery/MPPT電源電圧指令chを割り当てる。
- [ ] Battery/MPPT電源電流制限chを割り当てる。
- [ ] FK負荷電流指令chを割り当てる。
- [ ] 予備または補正用chの割当を決める。

## D. 高電力回路と安全

- [ ] 二電源のORing方式を決める。
- [ ] 逆流防止素子および定格を選定する。
- [ ] 突入電流抑制方式を決める。
- [ ] 過電流、過電圧、逆極性、過熱保護を設計する。
- [ ] 電源および負荷のON/OFF端子を絶縁リレーまたはフォトカプラ経由にする。
- [ ] ソフトウェアとは独立した物理非常停止を実装する。
- [ ] 非常停止操作で負荷、補助供給、電源出力が安全順序で遮断されることを確認する。
- [ ] 低電力条件で逆流および異常発熱が無いことを確認する。

## E. 計測・ログ

- [x] INA780モニタ用Python画面を作成する。
- [x] INA780高速ストリームおよびグラフ表示を実装する。
- [ ] 主電源、補助電源、DCバス、負荷のINA780配置を確定する。
- [ ] 計測点ごとのI2Cアドレスと配線図を作成する。
- [ ] シナリオ、STEP、電力値、Alert、切替イベントをCSV保存する。
- [ ] 切替瞬間の高速計測に用いるオシロスコープまたはDAQを選定する。
- [ ] 高速計測のプローブ位置とトリガ条件を決める。

## F. 制御ソフトウェア

- [x] EX/FK用Python制御UIを作成する。
- [x] ESP32-S3とMCP4728のSerial JSON制御を確認する。
- [ ] Python UIへ `H1/H2/H3/D1/D2` シナリオ選択を追加する。
- [ ] Python UIへSTEPテーブル編集、開始、停止、ログ保存を追加する。
- [ ] Python UIへ `MPPT / PV` モード比較画面を追加する。
- [ ] ESP32へ二電源DAC指令と切替出力を追加する。
- [ ] ESP32へPC通信断時の安全停止を実装・試験する。
- [ ] 補助供給切替判断をESP32ローカル状態機械として実装する。

## G. RC_IN / RPM / GK連携

- [ ] RC_INの電圧レベルとPWM範囲を実測する。
- [ ] `PWM_MAX_US` と100%判定許容幅を決める。
- [ ] ESP32でRC_IN PWMキャプチャを実装する。
- [ ] スロットルカット出力先および安全側動作を定義する。
- [ ] RPM取得元を決定する。
- [ ] `RPM_DROP_FLAG` の閾値と検知保持時間を決める。
- [ ] GK基板との通信プロトコルを確定する。
- [ ] Alert受信と表示優先ルールを実装する。
- [ ] Alert無し時の航行モード色5秒点灯を実装する。

## H. 段階試験

- [ ] Phase 0: MCP4728全ch単体電圧試験を完了する。

- [ ] Phase 2: 電源1台 + FK負荷の36V STEP試験を完了する。
- [ ] Phase 3: INA780およびCSVログが指令値と整合することを確認する。
- [ ] Phase 4: PV用電源とBattery/MPPT用電源を個別に試験する。
- [ ] Phase 5: 切替回路を低負荷で試験し、逆流と異常電圧が無いことを確認する。
